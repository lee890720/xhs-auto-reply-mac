X 账号

用 X 官方 API。在开发者后台把 App 权限设为 Read and Write，改完权限再生成 Access Token（之前生成的令牌仍是只读的）。

四个值都在开发者后台 → 你的 App → Keys and tokens。只保存在本机数据库。 打开开发者后台 →
「测试连接」只能验证密钥能读；有没有写权限，要等第一次真正发送才知道。

X 回复策略

只回复 @ 了你的推文（包括回复你推文的人），每条最多回一次。没有关键词搜索 —— 那是 X 明确禁止的。

X 开发者指南规定，用 AI 生成并自动发布回复，必须事先通过 X 的 Policy Support 表单申请批准； 没勾选这一项就不能切到全自动。全自动运行的账号还要在资料页开启「Automated」标签、简介里写明是机器人以及谁在运营。 申请表单 →

X 新关注者

定时检查新关注你的人。默认放进「X 新关注者」页由你逐个决定；打开下面的自动回关后，没有可疑标记的会被自动回关。

X 开发者指南把「自动回关所有关注者」列为批量/激进关注，打开后有被限制关注、App 被停用乃至封号的风险。 开启后仍有这些限制：带疑似机器人标记的不会自动回关（留在列表里由你决定）；每日自动回关有单独上限； 两次自动回关之间间隔 2–5 分钟；X 一拒绝关注（关注受限或频率限制），自动回关会被自动关闭并在顶部提示。

X 回复人设

和小红书分开。默认按对方的语言回复，不带 @、话题标签和链接；被问是不是机器人一律转人工，不冒充真人。
